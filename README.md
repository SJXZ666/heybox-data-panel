# 小黑盒数据面板

把自己小黑盒账号的创作数据抓到本地，做成一块只在本机运行的面板：看每篇的真实表现、每天新增多少浏览、下一篇大概能到多少，以及最近这段写作有没有变化。

不联网、不上传、不碰账号密码——抓取走的是你自己已登录的 Edge 创作中心。

![总览](docs/screenshots/overview.png)

## 它回答什么问题

- **这篇到底算好还是差？** 不看平台给的「内容得分」，看这篇在你自己账号里的相对位置：浏览量、互动质量（相对同浏览量的预期值）、传播、点击率，加权成 0–100 的真实得分。
- **每天涨了多少？** 每天 18:00 抓一次，存快照，算「当天 − 前一天」的增量，而不是累计总量。
- **下一篇大概能到多少？** 用最近 24 小时的增量加速度，配合 48 小时衰减曲线外推 14 天；预测会写进文件，到期后自动回看、校准系数。
- **最近写得怎么样？** 按「最近两周 / 前两周 / 更早」分桶做诊断，引用正文原句，给改写示范。

## 功能

| 页面 | 内容 |
| --- | --- |
| 总览 | 本月目标、历史最好 vs 最近 10 篇平均、最近发布 |
| 内容 | 搜索、按任意列排序、真实得分、计入/排除 |
| 图表 | 每日新增、每月发布与浏览、真实得分前 12、曝光→点击率、浏览×点赞率散点、发布热力图 |
| 单篇 | 各项指标、vs 账号平均、正文预览、48 小时曲线、浏览量预测、两篇对比 |
| 分析 | 调用模型生成账号诊断（可选，需要 API Key） |
| 设置 | API Key、模型、每日抓取时间、月度与单篇目标、账号切换 |

## 快速开始

**方式一：便携包（推荐给不想装环境的人）**

1. 解压压缩包（`node.exe` 已内置，不需要安装 Node）。
2. 双击 `启动.cmd`，浏览器打开 `http://127.0.0.1:7789/`。
3. 设置 → 账号 → 打开登录页，在弹出的 Edge 里登录小黑盒，关掉窗口。
4. 点右上角「重新抓取」，等 30 秒左右。

**方式二：从源码跑**

```bat
git clone <this-repo>
cd heybox-data-panel
npm install --prefix web
npm run build --prefix web
node server.mjs
```

需要 Node 20+ 和 Microsoft Edge。构建产物在 `web/dist`，`server.mjs` 会优先服务它；旧的单文件版仍在 `/old`。

## 工作原理

1. **抓取**：用独立的 Edge 配置（`edge-profile`）打开创作中心，等页面自己算好签名，再通过 CDP 拿到已签名的接口地址；随后由 Node 带 cookie 直接请求 `author/concept/article/list` 与 `article/data`。
2. **正文**：另开分享页，截获 `bbs/app/link/tree` 响应里的 `text` 字段（HTML 片段），剥标签后存 `bodies.json`。每篇只抓一次。
3. **存储**：全部落在本地 JSON——`data.json`（最新数据）、`history.json`（每日快照）、`bodies.json`（正文）、`exclude.json`（不计入的篇目）、`config.json`（设置）。
4. **面板**：React + Vite + Tailwind，`server.mjs` 只监听 `127.0.0.1`。

## 隐私

- 不连接任何第三方服务器；只有点「生成分析」时，才会把统计数据和正文片段发给你自己填的模型接口。
- `.gitignore` 已排除 `edge-profile`、`accounts`、`data.json`、`config.json` 等本地数据，仓库里不会有登录态和 API Key。

## 限制

- 只支持小黑盒。换平台要重写抓取。
- 只读创作中心能看到的公开数据，看不到读者画像。
- 曝光字段由平台定义，面板只算点击率，不解释平台口径。
- 预测基于历史曲线，新账号或发文很少时参考价值有限。
- 需要 Edge 登录一次；换号需要重新登录。
